### 현재 기능 요약

- **3D 거리:** 3인칭 이동(WASD, Shift 달리기), 드래그·Q/E 카메라, 모바일 조이스틱. 걷는 사람은 비켜 가고, 택시는 신호와 플레이어 앞에서 멈춘다.
- **미션 5개 (!):** 카페 주문(Scene Director), 핫도그, 길 묻기, 호텔 체크인, 지하철 문의. 성공 판정은 규칙(정규식, Director)이 한다.
- **자유 대화 12명 (말풍선):** 인사 → 내 소개 → 질문 → 작별 인사를 하면 대화 목표 달성이다(D-032).
- **대화 후:** 문법·표현 피드백, 복습 문장, 다시 들어볼 구간(내 녹음 재생), 따라 말하기.
- **평가:** 대화 케이스, 피드백 라벨, 합성 음성 ASR 하네스, 결과 비교 리포트(`#/report`, GitHub Pages 포함).
